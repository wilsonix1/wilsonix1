# AI Showcase Portfolio

A static portfolio for an AI Powered Automation Agents curriculum and AI Showcase Series.

## Includes

- Comprehensive AI curriculum modules
- Smart Memory and Smart Notes knowledge management track
- Modern web search with LLMs
- Telegram AI assistant project path
- Creative AI generation projects
- AI-generated website, ad campaign, brochure, narrative, presentation, and 3D product showcase deliverables
- Responsive layout, showcase filters, and canvas-based product demo

## Open Locally

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.
